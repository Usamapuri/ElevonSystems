## Global Constraints (verbatim from the spec and CLAUDE.md)

- Every report and the dashboard filter on `business_date` (invoices, receipts) / `business_day_id` — never on `created_at`. Voided invoices and voided receipts are excluded from every total; void counts are reported separately.
- One `reports.LoadPeriodSummary(ctx, db, from, to)` feeds the dashboard KPIs, the daily report totals and the Excel "period pack"; the Z-report's sealed figures for a closed day must equal the daily report's row for that date (test pins this on a seeded day).
- `net_sales = Σ total_payable` (ruling from Phase 3); `gross = Σ subtotal`; `discount = Σ discount_amount`; `taxable = Σ (subtotal − discount)`; `tax = Σ tax_amount + Σ further_tax_amount` shown separately; `rounding = Σ rounding_adjustment`. Tender split incl. on-account; `receipts_collected` per method.
- Tax report groups by effective rate band (`tax_rate` snapshot on the invoice): taxable, tax, further tax, invoice count; the grand total reconciles to Σ `tax_amount` by construction (test).
- Receivables: per customer balance = Σ debit − Σ credit; ageing buckets 0–30 / 31–60 / 61–90 / 90+ by allocating receipts FIFO against credit invoices by `business_date` in SQL or Go (deterministic, tested with a seeded ledger).
- Dates on the wire are ISO `YYYY-MM-DD`; labels in responses are `DD-MM-YYYY`; hourly buckets use the business timezone (sessions are `Asia/Karachi`).
- Exports: CSV `text/csv` with `Content-Disposition: attachment; filename="<report>_<from>_<to>.csv"`; Excel `.xlsx` via `writeWorkbook`, every cell through `neutralizeXLSXCell` (prefix `=+-@` with `'`). `Content-Disposition` is already in `ExposeHeaders`.
- Receipts: `POST /customers/:id/receipts` and `POST /customers/:id/receipts/:rid/void` exist (Phase 3); the UI needs an open day and shows `day_not_open` as a banner link to `/day-close`.
- All routes on `staff`/`admin` (`/admin/dashboard` and `/admin/reports/*` admin-only; receipts staff); `APIResponse` envelope; stable snake_case codes; never `err.Error()`. Route guards via `beforeLoad`; `routeTree.gen.ts` regenerated by `npx vite build` and committed (dashboard/reports routes already exist as placeholders, so no change expected).
- Commits `<scope>(<subsystem>): E-05 — <imperative>`, trailer `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`. Gate: `cd backend && go vet ./... && go test ./...` (with `TEST_DATABASE_URL`), `cd frontend && npm run type-check && npm run test && npx vite build`. No Bhookly references.

### Task P1 (E-05): `internal/reports` — period summary, report queries, exports

**Produces:**
```go
package reports
type Range struct{ From, To time.Time }               // inclusive business dates
type TenderSplit struct{ Cash, Card, Online, OnAccount float64 }
type PeriodSummary struct {
  From, To string; Invoices, Voids int; KgSold float64
  Gross, Discount, Taxable, Tax, FurtherTax, Rounding, Net float64
  Tenders TenderSplit; Receipts TenderSplit /* OnAccount unused */; ReceiptsTotal float64
}
func LoadPeriodSummary(ctx context.Context, db Querier, r Range) (PeriodSummary, error)
type DailyRow struct{ BusinessDate, Label string; PeriodSummary }  // one per date with activity
func Daily(ctx, db, r) ([]DailyRow, error)
type ProductRow struct{ ProductID *uuid.UUID; Name string; Kg float64; Invoices int; Gross, Share float64 }
func Products(ctx, db, r) ([]ProductRow, error)
type TaxBand struct{ Rate float64; Invoices int; Taxable, Tax, FurtherTax float64 }
func TaxBands(ctx, db, r) ([]TaxBand, error)   // Σ Tax == Σ invoices.tax_amount in range (test)
type CashierRow struct{ CashierID *uuid.UUID; Name string; Invoices int; Gross, Average float64; Voids int }
func Cashiers(ctx, db, r) ([]CashierRow, error)
type HourRow struct{ Hour int; Invoices int; Net float64 }
func Hourly(ctx, db, r) ([]HourRow, error)     // EXTRACT(HOUR FROM created_at) in session tz
type ReceivableRow struct{ CustomerID uuid.UUID; Name, Phone string; Balance, B0_30, B31_60, B61_90, B90 float64; LastReceipt *string }
func Receivables(ctx, db, asOf time.Time) ([]ReceivableRow, error)
type DayCloseRow struct{ ID uuid.UUID; BusinessDate, Label, Status string; ClosedBy string; ExpectedCash, CountedCash, CashVariance, CardVariance, OnlineVariance float64; Net float64 }
func DayCloses(ctx, db, r) ([]DayCloseRow, error)
func WriteCSV(w io.Writer, headers []string, rows [][]string) error
type sheetSpec struct{ Name string; Headers []string; Rows [][]any }
func writeWorkbook(w io.Writer, sheets []sheetSpec) error   // excelize; every string via neutralizeXLSXCell
func neutralizeXLSXCell(v any) any
```
**Tests (DB-backed, seed via direct INSERTs of invoices/lines/receipts/ledger/business_days across 3 business dates incl. one voided invoice and one voided receipt):** summary totals; a closed day's sealed `business_days` columns equal `Daily` for that date; tax bands reconcile; products share sums to 100 %; receivables FIFO ageing on a hand-computed ledger (invoice 1,000 at −70 d, invoice 2,000 at −20 d, receipt 1,200 at −10 d → 0–30: 1,800, 61–90: 0, 31–60: 0, 90+: 0 — i.e. receipt allocated to the oldest first); hourly bucket uses Asia/Karachi (insert `created_at` at 23:30 UTC → hour 4); `neutralizeXLSXCell("=SUM(A1)")` → `'=SUM(A1)`; CSV escaping.

Commit `backend(reports): E-05 — period summary, report queries, CSV/Excel writers`.

### Task P2 (E-05): Dashboard and reports API

Tests: each name returns 200 JSON with the seeded totals; csv/xlsx set headers and parse back (read the xlsx with excelize in the test).
